# Принятый долг (поправить позже, сейчас не проверять)

1. **mssql `OUTPUT` / fb `RETURNING` → `rowsAffected`** не поддерживается : требуют распознавания OUTPUT/RETURNING в SQL — отдельная задача.

2. **mssql abort до захвата соединения** → `request.cancel()` может не сработать (приватный API, риск).

3. **fb**: monkey-patch `attach`, глобальный `exports.connection`, exact-pin `node-firebird@2.19.1`, deep-import'ы без расширений, новый attach + rip сокета на каждый запрос.

4. **mssql**: приватные `_currentRequest`/`_acquiredConnection`, отдельный пул на транзакцию.

5. **pg**: внутренности `processID`/`connection.stream`, `_cancelBackend` (соединение на каждый abort).

6. **ora**: `close(0)` обрывает чужие активные соединения.

7. **TLS-дефолты** (`encrypt=false`, `rejectUnauthorized:false`).

8. **fb `connLost` во время летящего COMMIT**: низкий риск; завершение COMMIT полагается на node-firebird (`dropConnection`); без дедлайна жёсткой границы нет.

9. **гонка `index.ts close()` / `execStream`**: `_adapterPromise` не сбрасывается, но адаптеры лениво пересоздают пул — допустимо.
